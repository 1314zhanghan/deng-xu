# 灯叙 · Z测试版

> 一个**题材无关**的 AI 文字冒险引擎。世界观、角色、数值体系全部由你自定义，
> 像写角色卡一样写一个世界，AI 就能带你和你的角色把故事跑起来。

# 🎮 **https://fyjsj-zh.github.io/deng-xu/**

打开即可玩。第一次进入会弹「模型设置」，填入**你自己的 API Key** 就能开始 ——
Key 只存在你的浏览器里，本站不经过任何第三方服务器。

---

## 这个引擎能做什么

### 世界观与角色完全自定义
不预设任何题材。奇幻、赛博、太空、日常、恐怖、悬疑都行 ——
你写什么，引擎就按什么跑。

### 两段式生成（这个设计是核心）
把「写小说」和「算账」拆成两次调用：

1. **叙事 AI** —— 只写正文。它完全不知道数值存在，所以不会冒出
   「你的力量+1」这种出戏的句子。
2. **数据 AI** —— 读正文，输出结构化的 `stateChanges` 与下一步选项。

好处是两边互不污染：文风归文风，结算归结算。

### 数值体系由你定义
- **属性**：任意条数、任意名字（体魄 / 洞察 / 共鸣 / 隐匿……随你）
- **资源**：任意条数、可设上限；标「致命」的资源归零时 AI 会把故事引向结局
- **背景槽位**：类似「出身 / 牵挂」，每个选项可带属性加成与**开局携带物品**
- **预置物品与知识**：AI 会据此发道具、给线索，并**与你的出身挂钩**
- **章节卡事件**（可选）：你亲手写的固定剧情节点，带触发条件与选项

### 像素立绘 + 场景背景
- 角色立绘由 **LPC 模块化部件**合成，**调色板换色**：
  26 种发色 × 22 档肤色 × 24 种衣色 × 8 种瞳色，配合 60 件部件
- 同一个角色 id **永远得到同一张脸**（确定性生成），改名也不换脸
- 点任意角色头像可看**全身立绘**并切换四个方向
- 场景背景由 AI 通过 `SET_SCENE` 切换，且**不会每回合乱切**

### 兼容 SillyTavern 角色卡
角色卡字段对齐 **SillyTavern V2** 规范，可以直接导入现成的角色卡。

### 其他
- 存档导出 / 导入（换设备、清缓存前可备份）
- API 报错会**分类提示**并自动重试（限流、5xx、网络抖动）
- 手机、平板可用（本地起服务时同局域网设备可直接访问）

## 内置示例世界（三张，题材完全不同）

| 世界 | 题材 | 特色 |
|---|---|---|
| **《灰烬回响》** | 暗黑奇幻 | 5 个自定义属性、3 条资源、章节卡事件 |
| **《霓虹雨季》** | 赛博朋克 | 记忆擦除与档案交易，机制完整 |
| **《星海拾遗》** | 太空歌剧 | **纯叙事模式**（关闭机制层，只做对话与关系） |

> 《星海拾遗》是刻意关掉数值系统的示例 —— 用来说明「这个引擎不只能跑数值游戏」。

## 本地运行

```bash
pnpm install
pnpm dev            # 开发模式，改代码热更新
```

打开 http://localhost:5173 即可。想跑生产构建：

```bash
pnpm build
pnpm preview
```

Windows 也可以直接双击 **`start-dev.bat`**（开发模式）或 **`start.bat`**（生产构建）。

> ⚠️ **不要直接双击 `index.html` 或 `dist/index.html`。**
> 前者是 Vite 入口模板（引用未编译的 TypeScript），后者是 ES module ——
> `file://` 协议下浏览器会拦截，两者都必然白屏。必须走 HTTP。

想让手机访问本地服务：`start-dev.bat` 会把服务监听在局域网地址上，
按它打印的二维码或 IP 访问即可（首次会弹防火墙授权，选「允许专用网络」）。

## 关于 API Key

- **必须自备**。本站不提供 Key，也不做转发 —— 你的请求由浏览器直接发往你选择的服务商。
- Key **只存在你自己的浏览器** localStorage 里，不会上传到任何地方。
- 支持 DeepSeek 官方、OpenAI、硅基流动、OpenRouter、Ollama（本地）以及自定义接口。
- 想用本地模型：服务商选 `Ollama`，地址填 `http://localhost:11434` 即可。

---

## 数据存在哪里

| 数据 | 位置 | 说明 |
|---|---|---|
| API Key / 模型设置 | 浏览器 localStorage | 只在本机 |
| 游玩进度 | 浏览器 localStorage | **可导出备份**，见标题页「导出存档」 |
| 世界卡 / 角色卡 | 浏览器 IndexedDB | 卡片含头像 base64，所以走容量更大的 IndexedDB |
| 叙事 AI 的上下文 | 浏览器内存 | 不上传任何服务器 |

**换设备或清缓存前请先导出存档。** 存档接近浏览器容量上限时界面会给出警告 ——
因为配额耗尽后写入会**静默失败**，这是最容易被忽视的数据丢失场景。

## 项目结构

```
src/
  api/          LLM 调用、JSON 修复、错误分类
  components/   界面（叙事区、状态栏、立绘面板、卡片编辑器…）
  constants/    提示词
  data/         内置示例世界
  hooks/        游戏引擎（两段式流水线）
  stores/       Zustand 状态（game / session / library / ui / meta）
  utils/        立绘合成、换色、场景生成、存档、卡片读写
```

## 想改造它

- **换立绘素材**：`src/utils/lpcSprite.ts` 的配方池决定用哪些部件；
  换色基准色阶在同一个文件顶部的 `RAMP` 常量里。
- **换场景风格**：`src/utils/sceneArt.ts`，27 个程序化场景；
  `SceneAsset` 支持填 `image` 直接换成真实图片。
- **改提示词**：`src/constants/prompts.ts`。
- **加内置世界**：`src/data/builtinWorldsExtra.ts`，照现有结构加一个对象即可。
